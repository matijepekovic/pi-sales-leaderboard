Save Settings applies this schedule to work that has not yet been submitted. Keep automatic email printing enabled to continue collecting emails. Pause Email only pauses collection; it does not pause the print schedule.

Each scheduled release prints attachments collected by that time. Later arrivals wait for the next selected day. After worker downtime, an overdue batch is released when the worker returns. A released batch keeps retrying if the printer is offline.

Hold queue disables automatic releases without stopping email collection. Print queued now releases the current batch once without changing your schedule. Test Print always prints immediately. Switching to Print as emails arrive releases waiting reports. Already submitted jobs cannot be recalled by changing this setting.
