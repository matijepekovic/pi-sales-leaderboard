How reports print

Excel reports keep their original cells, colors, fonts, merged headings, column widths, row heights and totals. Nothing is split by Sub Status or rebuilt into a new table.

Paper, orientation, color, sides and copies apply to all new reports. They are job options, not changes to your Konica queue or Account Track. Received PDF files are never rewritten, split or subject to the Excel page limit.

Excel page layout

{% for key in ['EXCEL_SCALE', 'EXCEL_MARGINS', 'EXCEL_SHEETS', 'EXCEL_PAGE_POLICY'] %} {% endfor %}

Keep workbook settings uses the saved print areas, margins, orientation and scaling. Files with no saved page setup use LibreOffice's defaults. Fit each sheet on one page may make a large report very small. A workbook with multiple sheets may still produce multiple pages.

These are saved defaults for future jobs, not per-report rules. Already prepared/submitted jobs retain their own settings so retries cannot change a report halfway through. Error sheets always use one copy, single-sided Letter paper.

LibreOffice renders Excel files on the Pi; fonts and some Excel features can differ from printing in Microsoft Excel. The generated PDF in each job shows the rendered layout. Color, sides and paper selection still depend on the printer's capabilities.
